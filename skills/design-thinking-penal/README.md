# Design Thinking Penal Skill

Pacote de Skill para aplicar Design Thinking ao Direito Penal brasileiro.

Arquivos:

1. SKILL.md
   Instruções principais da Skill.

2. templates/checklist.md
   Checklist operacional para revisar petições penais.

3. templates/bloco_final.md
   Bloco pronto para inserir ao final de memoriais, recursos, pedidos de liberdade e demais peças penais.

Uso sugerido:

1. Copie a pasta para o ambiente de Skills.
2. Use a Skill sempre que trabalhar com defesa penal.
3. Para cada caso, forneça fatos, peça desejada, estágio processual, provas disponíveis e objetivo defensivo.
4. A Skill retornará diagnóstico, teses, estrutura da peça, argumentos e bloco final de Design Thinking Penal e Legal Design.
